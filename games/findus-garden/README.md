# Neues von Pettersson und Findus

Experimental Director 6 port. The selected edition is pinned in
[game.toml](game.toml); [journeys.json](journeys.json) defines its regression route.

See [validation and remaining blockers](../../docs/additional-ports.md) before building.

```sh
uv run --locked director64 web --game findus-garden
uv run --locked director64 journey --game findus-garden
```
