# Löwenzahn 5

Experimental Director 8 port. The selected edition is pinned in
[game.toml](game.toml); [journeys.json](journeys.json) defines its regression route.

See [validation and remaining blockers](../../docs/additional-ports.md) before building.

```sh
uv run --locked director64 web --game loewenzahn-5
uv run --locked director64 journey --game loewenzahn-5
```
